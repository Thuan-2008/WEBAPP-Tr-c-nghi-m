☁️ Đồng bộ giữa các máy

Đồng bộ thư viện đề, thư mục, bài đang làm, sổ câu sai và lịch sử qua GitHub Gist riêng tư của bạn. Dán cùng một token trên mọi máy.

Cách lấy token (làm 1 lần)
  1. Đăng nhập GitHub, mở trang tạo token (đã chọn sẵn quyền gist).
  2. Mục Expiration chọn No expiration.
  3. Kéo xuống bấm Generate token, sao chép mã bắt đầu bằng ghp_.
  4. Dán vào ô trên và bấm Kết nối. Trên máy khác dán đúng mã này.

Token chỉ lưu trên máy của bạn, và chỉ có quyền đọc/ghi Gist. Dữ liệu nằm trong một Gist bí mật tên json-quiz-data.json.

Mỗi câu là một mảng:

// Câu nhiều lựa chọn (loại 0)
[0, "Nội dung câu hỏi", "Đáp án A|Đáp án B|Đáp án C|Đáp án D", 1, "Gợi ý/chủ đề", "Giải thích"]
// → số 1 là vị trí đáp án đúng (tính từ 0: 0=A, 1=B, 2=C, 3=D)

// Câu Đúng/Sai (loại 1)
[1, "Mệnh đề", 0, "Gợi ý/chủ đề", "Giải thích"]
// → 1 = Đúng, 0 = Sai

Cũng hỗ trợ dạng object: {"question": "...", "options": [...], "answer": 0, "explanation": "..."}
